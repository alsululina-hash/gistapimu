# Гистоатлас к колку

Интерактивные препараты, электронограммы, теория и тесты по гистологии (темы 14–21).

Открыть локально: дважды кликнуть `index.html`.

Сайт на GitHub Pages: Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
